## About This Challenge

The goal of this challenge is not just to “use Terraform”, but to actually understand:

- how infrastructure works  
- how to define it using code  
- and how to think more structurally about systems  

I’ll be documenting:
- what I learn  
- what confuses me  
- what breaks (and how I fix it)
